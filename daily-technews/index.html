F5 corrige dix failles du serveur web nginx, dont deux qui permettent de prendre la main sur un serveur à distance par HTTP/2

F5, qui maintient le serveur web open source nginx, a publié le mercredi 18 novembre des correctifs pour dix vulnérabilités de nginx Open Source et de nginx Plus. Deux d'entre elles, CVE-2026-123633 et CVE-2026-123007, permettent d'exécuter du code à distance, sans identifiant, sur un serveur où HTTP/2 est activé. Wiz, qui les a signalées, les note 9,2 sur 10 (CVSS 4.0).

CVE-2026-123633 est une utilisation de mémoire après libération dans la gestion des connexions HTTP/2 : nginx libère la mémoire d'une connexion alors qu'une requête s'en sert encore. CVE-2026-123007 est une erreur de calcul dans le compteur qui règle le contrôle de flux de HTTP/2, qui aboutit à une copie de mémoire invalide. Wiz dit avoir mené l'attaque sur un serveur qui ne sert que des fichiers statiques, sans application derrière lui ni module tiers. La première faille touche les versions 1.19.7 à 1.31.8, la seconde toutes les versions depuis la 1.9.5, sortie en 2015, selon Wiz.

Les versions corrigées de nginx Open Source sont la 1.30.7, branche stable, et la 1.31.9, branche principale, selon heise. Pour nginx Plus, les correctifs sont dans les versions 37.0.7.1 et 37.2.0.1 pour la première faille, 37.0.8.1 et 37.3.0.1 pour la seconde, selon Wiz. F5 dit n'avoir trouvé aucune trace d'exploitation de ces failles. En attendant la mise à jour, Wiz conseille de désactiver HTTP/2 avec la directive http2 off;. nginx sert environ un tiers des sites web, soit près de 225 millions, selon l'enquête de septembre de Netcraft citée par The Register.

Plusieurs équipes ont trouvé ces failles chacune de leur côté : Wiz, Ikotas Labs, Metnir, Rapid7 et Xint, la plupart avec l'aide d'outils d'IA, selon The Register. Wiz dit les avoir trouvées avec Wiz Atlas, son outil d'analyse de code par IA, et les avoir signalées à F5 entre le 21 octobre et le 16 novembre. Rapid7 a publié un code de démonstration de CVE-2026-123007. Xint dit qu'un scan automatisé, sans intervention humaine, a trouvé quatre autres failles de nginx, et qu'une faille du noyau Linux combinée à l'une d'elles donne les droits d'administrateur sur la machine ; l'entreprise a nommé cet ensemble « nginx2root ». Ces résultats sont fournis par les entreprises et ne sont pas vérifiés par un tiers.

Information du 18 novembre. Sources : Wiz, The Register, heise

Deux versions piégées d'agent-framework, la bibliothèque Python de Microsoft pour créer des agents d'IA, volent des identifiants cloud

Deux versions malveillantes, 1.26.1 et 1.26.2, d'agent-framework, la bibliothèque Python officielle de Microsoft pour construire des agents d'IA, ont été publiées le mardi 17 novembre sur PyPI, le dépôt de paquets de Python, avec le compte éditeur de Microsoft. Le paquet est téléchargé près de 200 000 fois par mois, selon The Register. Selon l'analyse d'OpenSourceMalware, chaque version installe un fichier .pth que Python exécute à chaque démarrage, même si la bibliothèque n'est jamais importée. Le code relève les variables d'environnement et les fichiers d'identifiants (Azure, AWS, GitHub, Docker, Hugging Face, npm), demande de nouveaux jetons d'accès à Azure, Azure DevOps et GitHub Actions, puis envoie le tout vers une adresse du service webhook.site. Le paquet piégé s'appuie sur la version légitime 1.26.0 du cœur de la bibliothèque, qui continue donc de fonctionner, selon BleepingComputer. La seconde version a été publiée après la mise en quarantaine de la première : l'attaquant gardait un accès à la publication, et la manière dont il l'a obtenu n'est pas connue. Microsoft a rendu privés plusieurs dépôts « le temps d'enquêter sur du contenu malveillant », selon un porte-parole cité par The Register. Les chercheurs recommandent de considérer comme volés tous les identifiants accessibles depuis une machine où l'une des deux versions a été installée.

Information du 17 novembre. Sources : OpenSourceMalware, The Register, BleepingComputer

Allemagne

Codeberg, plateforme associative d'hébergement de code, reste injoignable au moins trois heures après la suspension de son domaine par NameSilo

Le domaine codeberg.org, qui donne accès à Codeberg, plateforme allemande d'hébergement de code open source gérée par une association, a cessé de répondre le mercredi 18 novembre au matin. À 9 h 13, heure de Paris, Codeberg a indiqué que le domaine, enregistré chez l'américain NameSilo, avait « entièrement disparu » de son compte ; l'association dit ne pas avoir oublié de le renouveler et n'avoir trouvé aucune connexion suspecte. NameSilo lui a ensuite confirmé que le domaine était suspendu et que le dossier était transmis à son service chargé des abus. Le domaine était retiré du DNS : le site, mais aussi le clonage et l'envoi de code par Git, étaient inaccessibles, selon Linuxiac. Forgejo, le logiciel sur lequel tourne Codeberg, n'a pas pu publier comme prévu une mise à jour de sécurité, selon heise. Codeberg a renoncé à basculer sur son domaine codeberg.eu, en invoquant la double authentification, la gestion de plusieurs domaines et les adresses de dépôts à changer. À 12 h 23, l'association a annoncé que le domaine redevenait accessible, sans avoir reçu de réponse officielle de NameSilo sur le motif. Le registre du .org indique une échéance du domaine en 2028 et une dernière modification le 18 novembre à 12 h 02. Codeberg héberge notamment Forgejo, Zig et GNU Guix, et Gentoo y déplace ses dépôts depuis GitHub, selon Linuxiac.

Information du 18 novembre. Sources : Codeberg (compte de statut), heise, Linuxiac

États-Unis, Chine

Les États-Unis soumettent à licence les centres de données du monde entier qui louent de la puissance de calcul à des entreprises chinoises

La règle « Addressing Remote Access to Advanced Semiconductors » du Bureau of Industry and Security (BIS), le service du département du Commerce américain chargé du contrôle des exportations, annoncée le lundi 16 novembre, est publiée ce jeudi 19 novembre au Federal Register, date de son entrée en vigueur. Elle impose une licence à tout centre de données, où qu'il se trouve, qui fournit plus de 12 millions d'unités de TPP, la mesure de puissance de calcul des règles américaines, à des entreprises dont le siège est en Chine, à Macao ou dans un autre pays soumis à un embargo américain sur les armes. Les centres qui servent déjà ces clients ont 90 jours pour obtenir une licence. L'exportation de puces avancées vers l'Indonésie, la Malaisie, Singapour, la Thaïlande et le Brésil, que la règle juge exposés à un « risque de détournement plus élevé que la normale », exige aussi une licence, sauf pour les acheteurs dont le siège est aux États-Unis, qui doivent alors faire l'objet de rapports mensuels. Les systèmes de recommandation des sites marchands et des réseaux sociaux sont exemptés. La règle abroge aussi l'AI Diffusion Rule de l'administration Biden, qui n'avait jamais été appliquée, selon The Next Web. Le président de Tencent, Martin Lau, a déclaré lors de la présentation des résultats trimestriels du groupe que ces restrictions « font reculer tout le monde en Chine », en particulier pour l'entraînement des modèles d'IA, selon The Register.

Information du 19 novembre. Sources : Federal Register, The Next Web, The Register

L'outil open source du jour

Kitesurf, le moteur de navigateur de Cloudflare pour les agents d'IA, publié sous licence Apache 2.0

Kitesurf est un moteur de navigateur expérimental qui tourne sur Cloudflare Workers, le service d'exécution de code de Cloudflare. Il lit le HTML, applique le CSS, exécute le JavaScript des pages et produit des captures d'écran, sans Chrome ni conteneur de navigateur. Il parle le Chrome DevTools Protocol, ce qui permet de le piloter avec des outils comme Puppeteer. Son cœur est écrit en Rust et compilé en WebAssembly, à partir de bibliothèques open source pour l'analyse du HTML et du CSS, la mise en page et le rendu.

Cloudflare a publié le code sur GitHub sous licence Apache 2.0, selon heise le 18 novembre ; la dernière version du dépôt, 2026.11.10, date du même jour. Selon les mesures de Cloudflare, Kitesurf consomme nettement moins de processeur et de mémoire que Chromium pour les captures d'écran et l'extraction de HTML, mais met environ deux fois plus de temps au total ; ces mesures ne sont pas vérifiées par un tiers.

Dépôt : github.com/cloudflare/kitesurf, consulté le 19 novembre.
